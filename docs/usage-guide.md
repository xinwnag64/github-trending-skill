# 使用教程

## 一、技能导入步骤

1. 打开豆包客户端，进入「技能中心」
2. 点击右上角「添加」→「创建技能」
3. 填写技能名称与描述
4. 将 `prompt/v2.0.0_prompt.md` 中的内容完整粘贴到系统提示词框
5. 点击保存，技能创建完成

> 也可以直接上传 `skill-package/` 文件夹导入标准技能包。

## 二、调用方式

在工作任务对话中直接发送指令即可，例如：

- 生成今日GitHub Trending Top10简报
- 本周GitHub热门项目总结
- 本月GitHub技术趋势分析
- 生成本周Python方向Top15趋势报告

## 三、参数说明

| 参数 | 可选值 | 默认 |
|------|--------|------|
| 周期 | 今日 / 本周 / 本月 | 本周 |
| 编程语言 | Python / TypeScript / Rust / Go 等 | 全语言 |
| 榜单数量 | Top 5 / 10 / 20 | Top 10 |

## 四、输出说明

- 输出为精美 HTML 可视化报告，包含：
  - 领域分布图（饼图/环形图）
  - Top 项目增速条形图
  - 项目卡片列表
  - 重点项目深度点评
  - 整体趋势总结
- 所有数据实时获取，以 GitHub 官方 Trending 数据为准
