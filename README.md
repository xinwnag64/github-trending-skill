# GitHub 趋势分析助手

通过 **GitHub 官方 Search API** 快速获取近期热门项目，生成**带对比追踪与科研价值标注的精美可视化技术趋势报告**的豆包自定义技能。

## ✨ 功能特性（V2.2）

- ⚡ **API 加速**：调用 GitHub 官方 Search API，无需打开浏览器，秒级响应
- 📅 **多周期切换**：今日 / 本周 / 本月（用户指定优先，未指定默认本周）
- 🌐 **语言筛选**：可指定 Python / TypeScript / Rust 等任意语言
- 📊 **对比追踪**：新晋项目标注、上升最快排序、活跃度判断
- 🎓 **科研标注**：科研潜力标签（论文选题/研究空白）、领域细分、学术热点关联
- 🖼️ **精美报告**：TL;DR 摘要 + 推荐关注清单 + 可视化图表 + 项目卡片，可导出 HTML
- 🔢 **自定义数量**：支持 Top 5 / 10 / 20

## 🚀 快速开始

1. 复制 `prompt/v2.2.0_prompt.md` 中的完整提示词
2. 打开豆包 → 技能中心 → 创建自定义技能 → 粘贴系统提示词
3. 在工作任务中发送指令即可调用

## 📌 指令示例

- 获取GitHub Trending Top10报告
- 本周GitHub热门项目总结
- 本月GitHub技术趋势分析
- 生成本周Python方向Top15趋势报告
